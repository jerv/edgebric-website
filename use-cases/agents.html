Edgebric

Edgebric + AI Agents

The private knowledge layer for autonomous AI. Your agent, your data, your hardware.

The problem

AI agents are powerful reasoners. But they have no long-term memory.

Your agent can browse the web, send emails, and write code. But it can’t search your private files, remember what you uploaded last week, or organize your knowledge over time.

Edgebric gives agents persistent, searchable, private knowledge. Documents stay on your hardware—agents query them, never copy them. Same privacy guarantees whether a human or agent is asking.

  • Agents forget everything between sessions
  • Cloud RAG services expose your data to third parties
  • Copy-pasting context into prompts doesn’t scale
  • Your agent needs a knowledge base it can trust

What agents can do

Full access. Not a second-class citizen.

Agents get the same capabilities as humans. Search, upload, create sources, manage data—all through a REST API.

Search with citations

Hybrid search (BM25 + vector). The /search endpoint returns raw ranked chunks—let your agent’s smart model synthesize. Faster and more accurate.

Upload and ingest

PDFs, DOCX, TXT, Markdown. Your agent uploads files and Edgebric chunks, embeds, and indexes them automatically.

Create and manage sources

Agents can create knowledge sources, organize data, and maintain your information over time. Full CRUD access.

Full RAG query

The /query endpoint runs the full pipeline—search, retrieve, synthesize with the local LLM. For agents that want a ready-made answer.

No local LLM needed

The /search endpoint skips the local model entirely. Your agent’s smart model (Claude, GPT-4) does the reasoning. Edgebric just provides the knowledge.

Private by architecture

Agent queries never leave your hardware. No data is sent to cloud services. The agent talks to Edgebric over your local network.

How it works

Simple REST API. API key auth. That’s it.

Three endpoints. If your agent can make HTTP requests, it can use Edgebric.

# Discover available data sources curl -H "Authorization: Bearer eb_your_key" \ http://localhost:3001/api/v1/sources # Search — returns ranked chunks, no LLM curl -X POST -H "Authorization: Bearer eb_your_key" \ http://localhost:3001/api/v1/search \ -d '{"query": "what is our refund policy?"}' # Full RAG query — search + local LLM synthesis curl -X POST -H "Authorization: Bearer eb_your_key" \ http://localhost:3001/api/v1/query \ -d '{"query": "summarize the Q3 report"}'

Security

You control what agents can access

Edgebric enforces the boundaries you set. Agents get exactly the access you give them—nothing more.

Scoped API keys

Create keys with read-only, read-write, or admin access. Each key is limited to specific data sources.

Per-source access control

Key A sees HR data. Key B sees Legal. Your agent only accesses what you explicitly allow.

Full audit trail

See exactly what every agent accessed, when, and what data was returned. Immutable logs.

Instant revocation

Revoke any API key immediately. The agent loses access in real time. No waiting, no expiry windows.

Getting started

Up and running in minutes

1. Install Edgebric

Download, install, add your data. Edgebric handles the AI setup automatically.

2. Create an API key

Generate a key in the admin panel. Choose access scope and which data sources it can see.

3. Point your agent at it

Give your agent the API key and endpoint. It starts searching your data immediately.

Give your agent a knowledge base
